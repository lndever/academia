# FitFam — Academia da Família & Amigos

App web de treinos, dieta, água e sono para usar com a família e amigos.

## Abrir o site

Depois de ativar o **GitHub Pages**:

**https://lndever.github.io/academia/**

(ou o link do seu repositório)

## Como ativar o GitHub Pages

1. Abra o repositório no GitHub
2. Vá em **Settings** → **Pages**
3. Em **Source**, escolha **Deploy from a branch**
4. Branch: **main** / pasta: **/ (root)**
5. Salve e aguarde 1–2 minutos

## Estrutura

```
index.html
css/style.css
js/app.js
js/data.js
```

## Recursos

- Perfis múltiplos
- Calendário de treinos

- Dieta e macros
- Controle de água
- Registro de sono
